# Asset Guide

Included:
- camera.svg
- flashlight.svg
- remote.svg
- ndi.svg

These are generic original UI icons. Replace them with the final design system if desired.

Recommended additional assets for the final app:
- AppIcon 1024x1024 PNG
- iPhone preview backgrounds
- status badges
- camera lens glyphs
- orientation glyphs
- audio input glyphs
- diagnostics icons

Do not copy NDI's proprietary logo into the app unless the applicable brand/trademark permissions permit it.
